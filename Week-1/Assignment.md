# Week 1 assignment — Explore, debug and propose
Work with the [actual OweBro codebase](https://github.com/vipul-LLM/Owebro). No predefined feature list or bug solutions are supplied: the goal is to investigate independently.

- [ ] Clone/fork the application and create a personal branch.
- [ ] Run frontend and backend locally; document setup blockers and attempted solutions.
- [ ] Map the folder structure and explain what frontend, backend and database do.
- [ ] Trace one existing user interaction through the frontend, HTTP request, backend and database where applicable.
- [ ] Test available user flows with dummy data; record expected versus actual behavior.
- [ ] Identify three genuine shortcomings or opportunities based on your own observations.
- [ ] Investigate at least one issue: reproduce, inspect logs/network, form a hypothesis, test it, and document results. A small fix on your branch is welcome but not required if blocked.
- [ ] Propose one meaningful frontend improvement and one meaningful backend improvement. Explain why each matters, likely files affected, feasibility and how you would test it.

## Deliverable
Complete the [submission template](Submission-Template.md) and share it with the mentor by the end of Week 1. Include sanitized evidence and your branch/fork link. Do not submit secrets or personal data. Discuss overlapping ideas before implementation. Weeks 2 and 3 focus on implementing the selected frontend and backend improvements; Week 4 focuses on integration, testing and collaborative deployment.
